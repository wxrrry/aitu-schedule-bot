# 🎓 Telegram Бот расписания занятий (9ПО-43к · AITU)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/wxrrry/aitu-schedule-bot)

Telegram-бот, который каждый день в **00:00** (по Московскому времени) автоматически присылает актуальное расписание занятий на наступающий день с учётом **числителя и знаменателя** (чётности недели).

---

## ⚡️ Возможности

- ⚡️ **Live-статус пар (`/now` или кнопка в меню)**:
  - Определяет текущую пару прямо сейчас, прогресс-бар `[▓▓▓▓░░░░░░] 45%`, оставшееся время до звонка и следующую пару.
  - Показывает статус перемены и время до конца обеденного перерыва.
- 🎨 **Стильный визуал и баннеры**:
  - Высококачественные баннеры-постеры для `/start`, звонков, бодрого утра в 08:00 и выходных дней.
  - Оформление карточек пар через элегантные Telegram `<blockquote>` с акцентными линиями.
- 📅 **Интерактивная навигация прямо под сообщением**:
  - Кнопки `[ ◀️ Вчера ] [ 🔄 Обновить ] [ Завтра ▶️ ]` редактируют сообщение на лету без лишнего спама в чат.
- 👨‍🏫 **Справочник преподавателей (`/teachers`)**:
  - Интерактивный каталог всех преподавателей группы с их кабинетами, предметами и подробным графиком пар.
- 📍 **Поиск пар по номеру кабинета (`/room <номер>`)**:
  - Быстрый поиск всех пар группы в конкретной аудитории (например, `/room 305`).
- 📥 **Экспорт в календарь смартфона (`/calendar` или `/ics`)**:
  - Генерация стандартного файла iCalendar (`.ics`), который в 1 клик добавляет все пары с числителем/знаменателем и напоминаниями за 15 минут в календарь iPhone / Android.
- ⏰ **Две автоматические рассылки**:
  - В **00:00 (MSK)**: подробное расписание на наступающий день.
  - В **08:00 (MSK)** (по будням): бодрое напоминание о первой паре сегодня (со скольки начинается учёба).
- 🔄 **Поддержка числителя / знаменателя**:
  - Автоматическое определение чётности недели и отображение плавающих пар.
- 🕒 **Расписание звонков (`/bells`)**: вывод времени каждой пары с разбивкой (45м + 5м перерыв + 45м) и обеда (12:20 — 12:55).
- 🛡 **Встроенный анти-сон для Render**: автоматический self-ping каждые 10 минут, предотвращающий засыпание бесплатного сервера.

| **1** | 09:00 — 10:35 | 09:00–09:45 • перерыв 5 мин • 09:50–10:35 |
| **2** | 10:45 — 12:20 | 10:45–11:30 • перерыв 5 мин • 11:35–12:20 |
| **Обед** | **12:20 — 12:55** | **Обеденный перерыв (35 минут)** |
| **3** | 12:55 — 14:30 | 12:55–13:40 • перерыв 5 мин • 13:45–14:30 |
| **4** | 14:40 — 16:15 | 14:40–15:25 • перерыв 5 мин • 15:30–16:15 |

## ☁️ Бесплатный хостинг 24/7

### Вариант 1: Render.com (Самый быстрый запуск через GitHub)
1. Зайдите на **[render.com](https://render.com)** и авторизуйтесь через **GitHub**.
2. Нажмите синюю кнопку **New +** → выберите **Web Service**.
3. Выберите ваш репозиторий **`wxrrry/aitu-schedule-bot`**.
4. Render автоматически увидит файл `render.yaml` или предложит заполнить поля:
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
   - **Instance Type**: `Free`
5. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN`: ваш токен от BotFather
   - `CHAT_ID`: `792569339`
6. Нажмите **Create Web Service**. Бот запустится за ~1 минуту!

---

### Вариант 2: Hugging Face Spaces (Бесплатный 24/7 Docker, без карт)
1. Зарегистрируйтесь на **[huggingface.co](https://huggingface.co)**.
2. Перейдите в **Spaces** → нажмите **Create new Space**.
3. Заполните параметры:
   - **Space name**: `aitu-schedule-bot`
   - **Space SDK**: выберите **Docker** → **Blank**
   - **Space hardware**: `Free CPU (2 vCPU · 16 GB)`
4. В созданном Space перейдите во вкладку **Files**:
   - Можно загрузить файлы репозитория или подключить GitHub.
5. Перейдите в **Settings** → **Variables and secrets** и добавьте secrets:
   - `BOT_TOKEN`
   - `CHAT_ID`
6. Space соберёт Dockerfile и будет работать 24/7 навсегда.

---

### Вариант 3: GitHub Actions (Автоматический будильник в 00:00)
Если вам достаточно ежедневной рассылки расписания в полночь (без необходимости 24/7 отвечать на кнопки), настроен workflow `.github/workflows/daily_schedule.yml`, который работает автоматически и бесплатно.
