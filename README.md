# 🎓 Telegram Бот расписания занятий (9ПО-43к · AITU)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/wxrrry/aitu-schedule-bot)

Умный Telegram-бот расписания для учебной группы **9ПО-43к** (4 курс, AITU). Бот автоматически учитывает **числитель и знаменатель**, плавающие пары, отмены и замены, ведёт личные и групповые рассылки, предоставляет инлайн-поиск и материалы по учёбе.

---

## ⚡️ Полный функционал

### 1. ⚠️ Замены и отмены пар в реальном времени
- **Добавление замен старостой/админом:**
  - ` /zamena 17.10 3 отмена` — отмена пары с мгновенным оповещением группы.
  - `/zamena завтра 2 МДК 07.01 Сертификация, каб. 305` — перенос/замена пары.
  - `/zamena del 17.10 3` или `/zamena_del 17.10 3` — удаление замены.
- **Интеграция во все разделы:**
  - В расписании на день и неделю отменённые пары перечёркиваются: `<s>Пара</s>` с пометкой `[❌ ПАРА ОТМЕНЕНА]`.
  - Заменённые пары подсвечиваются яркой плашкой `[⚠️ ЗАМЕНА: ...]`.
  - В `/now` бот сообщает об окне/отмене, а в утренней сводке (08:00) сдвигает время первой активной пары.
  - Просмотр всех актуальных замен по команде `/zameny` или кнопке «⚠️ Замены пар».

### 2. 💬 Инлайн-режим (`@aituraspisaniebot` в любом чате)
- Напишите `@aituraspisaniebot` в строке ввода любого диалога или группы:
  - 📅 **Сегодня** — свежее расписание дня с текущим статусом.
  - 🔜 **Завтра** — расписание на наступающий день.
  - ⚡️ **Какая пара сейчас?** — прогресс-бар и оставшиеся минуты.
  - 🗓 **Вся неделя** — расписание с понедельника по пятницу.
  - 📚 **Конспекты лекций** — мгновенный поиск и отправка карточек лекций (например `@aituraspisaniebot rest`).
  - ⚠️ **Замены и отмены** — список активных изменений.
  - 🔔 **Звонки и пятиминутки** — график звонков.
  - 📁 **СДО и материалы** — ссылки и титульный лист.
  - 🔍 **Поиск по кабинету или дню недели** (например: `@aituraspisaniebot 304` или `@aituraspisaniebot вт`).
> 💡 *Для активации инлайн-режима в своём боте отправьте боту @BotFather команду `/setinline` и введите любой плейсхолдер (например: `Поиск расписания...`).*

### 3. 📚 База конспектов лекций (4 курс 1 семестр)
- **Синхронизировано со всеми лекциями из базы знаний Obsidian:**
  - 🛡 **МДК 07.02** (15.10.2026, 16.10.2026 — Защита БД, НПА РФ, 149-ФЗ, 152-ФЗ, ФСТЭК № 64, ГОСТы, Defense-in-Depth).
  - 📊 **Менеджмент в ПД** (13.10.2026, 14.10.2026 — Эволюция, Друкер, Эйзенхауэр, Парето, Pomodoro, Социотехническая модель, SMART).
  - 💻 **МДК 04.01** (13.10.2026 — Архитектура REST API, 6 принципов Филдинга, JSON, кейс «Моя Кухня»).
  - 💼 **Экономика отрасли** (16.10.2026 — Рыночная экономика, ст. 2 ГК РФ, IT-экономика, ФОТ, marginal cost ≈ 0, формы бизнеса).
  - 🦺 **БЖД** (Сводный конспект курса — РСЧС, Гражданская оборона, СИЗОД ГП-7, АК-74, Первая помощь СЛР 30:2).
- **Интерактивные возможности:**
  - 📌 **Карточка лекции:** краткое резюме (TL;DR) и контрольные вопросы темы.
  - 📖 **Постраничное чтение:** удобный онлайн-ридер с постраничной навигацией (`◀️ Назад`, `Вперёд ▶️`) без спама и лимитов Telegram.
  - 📄 **Скачивание .md:** прямая отправка оригинального Markdown-файла для импорта в Obsidian или Notion.
  - 🔍 **Поиск лекций:** через команду `/lecture <тема/дата>` (например: `/lecture rest` или `/lecture 15.10`).
  - 📅 **Навигация по датам и предметам:** двухуровневый интерактивный каталог.

### 4. 📁 СДО Moodle и учебные материалы
- Команда `/moodle` или кнопка «📁 СДО и Материалы»:
  - Прямой вход на портал [moodle.astanait.edu.kz](https://moodle.astanait.edu.kz).
  - Описание учебных материалов 4 курса.
- **Официальный макет титульного листа (.docx)**:
  - Команда `/maket` или кнопка под сообщением мгновенно отправляет утверждённый файл `maket_titul_pz_lr.docx` для практических (ПЗ) и лабораторных (ЛР) работ прямо в Telegram!

### 5. 🔔 Личный колокольчик (напоминания за 10 минут)
- Команда `/remind` или кнопка «🔔 Мои напоминания»:
  - Персональная подписка каждого студента на напоминания перед парами в ЛС.
  - Автоматическая отправка уведомления ровно **за 10 минут до начала пары** (08:50, 10:35, 12:45, 14:30 по будням).
  - В сообщении: номер кабинета, предмет, ФИО преподавателя и структура пары.
  - Если пара отменена — бот предупредит, что приходить не нужно.

### 6. ⚡️ Live-статус занятий прямо сейчас (`/now`)
- Визуальный прогресс-бар `[▓▓▓▓▓░░░░░] 50%` и точное количество минут до конца пары.
- Оповещение о переменке (10 мин) и большом обеденном перерыве (12:20 — 12:55, 35 мин).
- Информация о следующей паре и кнопка `🔄 Обновить статус`.

### 7. ⏰ Автоматические рассылки и пятиминутки
- **00:00 (MSK)** — детальное расписание на наступающий день с баннером в группе.
- **08:00 (MSK)** (по будням) — утреннее напоминание о начале занятий и первой паре.
- **Пятиминутки внутри пар** — автоматические уведомления в группу в 09:45, 11:30, 13:40, 15:25 о 5-минутном перерыве внутри пары.

### 8. 📂 Удобное меню по папкам
- **Быстрый доступ:** `⚡️ Какая пара сейчас?`, `📅 Сегодня`, `🔜 Завтра`.
- **🗓 Расписание 📂:** Текущая неделя, Следующая неделя, Интерактивный выбор дня, Чётность недели.
- **🛠 Полезное 📂:** Звонки, Замены пар, Конспекты лекций, СДО и Материалы, Мои напоминания, Преподаватели, Поиск кабинета, В календарь.

### 9. 👨‍🏫 Преподаватели и поиск аудиторий
- `/teachers` — карточки всех преподавателей с их дисциплинами и расписанием по дням.
- `/room <номер>` — поиск пар в конкретном кабинете (например `/room 305`).
- `/calendar` — выгрузка `.ics` файла для Apple Calendar / Google Calendar с автоматическими напоминаниями.

1. Авторизуйтесь на **[render.com](https://render.com)** через GitHub.
2. Создайте **New Web Service** и выберите репозиторий `aitu-schedule-bot`.
3. Укажите переменные окружения:
   - `BOT_TOKEN`: токен от @BotFather
   - `CHAT_ID`: `-1002135486048` (ID группы)
   - `ADMIN_ID`: `792569339` (ID старосты/админа для замен)
   - `TIMEZONE`: `Europe/Moscow`
4. В боте уже встроен **автоматический анти-сон (Keep-Alive каждые 4 минуты)** на эндпоинт `/health`, благодаря чему бесплатный инстанс Render не засыпает.

### Вариант 2: GitHub Actions (Автономный дублёр)
В репозитории настроен `.github/workflows/daily_schedule.yml`, который бесплатно и гарантированно рассылает расписание в 00:00 и 08:00 по cron-триггеру GitHub.

## 🛠 Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/wxrrry/aitu-schedule-bot.git
cd aitu-schedule-bot

# Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Настройка окружения
cp .env.example .env
# Заполните BOT_TOKEN, CHAT_ID, ADMIN_ID

# Запуск бота
python bot.py
```
