# 🎓 Telegram Бот расписания занятий (9ПО-43к · AITU)

Telegram-бот, который каждый день в **00:00** (по Московскому времени) автоматически присылает актуальное расписание занятий на наступающий день с учётом **числителя и знаменателя** (чётности недели).

---

## ⚡️ Возможности

- ⏰ **Автоматическая рассылка в 00:00**: каждый день присылает расписание на новый день в личные сообщения или групповой чат.
- 🔄 **Поддержка числителя / знаменателя**: автоматически определяет чётность недели и подставляет нужные пары и аудитории (например, чередование МДК 04.01 и Физкультуры в понедельник, Менеджмента и МДК 07.02 во вторник).
- 🕒 **Расписание звонков**: вывод времени каждой пары и отметки обеда (12:20 — 12:55).
- 🏖 **Выходные дни**: по субботам и воскресеньям бот сообщает, что пар нет.
- 💬 **Интерактивные команды в чате**:
  - `/today` — Расписание на сегодня
  - `/tomorrow` — Расписание на завтра
  - `/week` — Расписание на текущую неделю
  - `/next_week` — Расписание на следующую неделю
  - `/parity` — Какая сейчас неделя (числитель или знаменатель)
  - `/chat_id` — Узнать ID чата для настройки рассылки

## ⚙️ Установка и локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/wxrrry/aitu-schedule-bot.git
   cd aitu-schedule-bot
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в `.env` и заполните:
   ```bash
   cp .env.example .env
   ```
   - `BOT_TOKEN`: токен от [@BotFather](https://t.me/BotFather)
   - `CHAT_ID`: ID чата, куда присылать расписание (узнать можно командой `/chat_id` в чате с ботом или через [@userinfobot](https://t.me/userinfobot))
   - `TIMEZONE`: `Europe/Moscow`
   - `ANCHOR_DATE`: `2026-10-12`
   - `ANCHOR_PARITY`: `chislitel`

5. Запустите бота:
   ```bash
   python bot.py
   ```

## 🌐 Как хостить БЕСПЛАТНО (3 способа)

### Способ 1: GitHub Actions (Самый простой и надёжный — 100% бесплатно навсегда)
В репозитории уже настроен workflow [`.github/workflows/daily_schedule.yml`](.github/workflows/daily_schedule.yml).

**Преимущества**: не требует серверов, не «засыпает», не просит привязки банковских карт.

1. Зайдите в ваш репозиторий на GitHub: **Settings** → **Secrets and variables** → **Actions**.
2. Добавьте два секрета (Repository secrets):
   - `BOT_TOKEN` — ваш токен бота от BotFather.
   - `CHAT_ID` — ID вашего чата или канала.
3. GitHub Actions будет **каждый день ровно в 21:00 UTC (00:00 MSK)** автоматически запускать скрипт `send_tomorrow.py` и отправлять расписание в чат!
4. Вы также можете в любой момент нажать кнопку **«Run workflow»** во вкладке **Actions**, чтобы протестировать отправку вручную.

---

### Способ 2: Koyeb / Render / Railway (Для 24/7 бота с командами)
Если хотите, чтобы бот не только присылал расписание в 00:00, но и отвечал на команды `/today`, `/tomorrow` круглосуточно:

1. **[Koyeb](https://www.koyeb.com)**:
   - Бесплатный тарифный план предоставляет 1 бесплатный сервис (Nano), который работает 24/7 без засыпания.
   - Подключите ваш GitHub репозиторий, укажите запуск через Dockerfile или команду `python bot.py`.
   - В разделе Environment variables укажите `BOT_TOKEN` и `CHAT_ID`.

2. **[Render](https://render.com)**:
   - Создайте **Background Worker** (или Cron Job).
   - Подключите репо, выберите команду запуска `python bot.py`.
   - Задайте переменные окружения.

3. **[PythonAnywhere](https://www.pythonanywhere.com)**:
   - В бесплатном тарифе есть вкладка **Tasks** (Scheduled tasks).
   - Задайте ежедневный запуск `python /home/username/aitu-schedule-bot/send_tomorrow.py` в нужное время UTC.

---
